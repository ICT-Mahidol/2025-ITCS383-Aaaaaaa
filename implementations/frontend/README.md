# Booth Organizer System - Frontend

A React-based frontend for the Booth Organizer System.

## Features

- **User Authentication**: Login and registration
- **Event Browsing**: View available events
- **Booth Selection**: Interactive booth reservation
- **Admin Dashboard**: Event and booth management for booth managers
- **Responsive Design**: Mobile-friendly interface

## Pages

- **Home**: Welcome page with feature overview
- **Login/Register**: User authentication
- **Events**: Browse available events
- **Booths**: View and reserve booths for specific events
- **Admin**: Dashboard for booth managers to manage events and booths

## Components

- **Navigation**: Site-wide navigation with authentication status
- **EventCard**: Display event information
- **BoothCard**: Display booth details and reservation status

## API Integration

Communicates with the FastAPI backend through RESTful APIs for:
- User authentication
- Event management
- Booth management
- Reservation handling

## Getting Started

```bash
npm install
npm start
```

Runs on `http://localhost:3000`
